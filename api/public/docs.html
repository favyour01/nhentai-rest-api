API Documentation

Complete reference for the nhentai REST API v2. All endpoints return JSON and require no authentication.

Introduction

This is an unofficial REST API for accessing nhentai doujin data. The API serves data from a local SQLite database with real-time auto-scraping from nhentai.net for missing/incomplete data.

⚡ Real-time Updates: The API automatically fetches complete data from nhentai.net when requested data is missing or incomplete. Only complete records (with media_id, thumbnails, etc.) are stored in the database.
⚠️ Disclaimer: This API is unofficial and not affiliated with nhentai.net. Data is provided for educational and research purposes only.

Base URL

https://api-ao1hjzaox-akatsuki.vercel.app

All API endpoints are prefixed with /api/v2. An alias /v2 is also available. Replace the base URL with your deployed Vercel domain.

Rate Limits

To ensure fair usage, the API is rate limited:

  • 300 requests per 15-minute window per IP
  • Rate limit headers are included in responses
  • Exceeding the limit returns 429 Too Many Requests

Response Format

All responses follow a consistent JSON structure:

{
  "success": true,
  "data": { ... },
  "pagination": { ... }  // Only for list endpoints
}

Error responses:

{
  "success": false,
  "error": "Description of what went wrong"
}

GET /api/v2/search

Search doujins with various filters. All query parameters are optional.

Query Parameters

ParameterTypeDescription
qstringSearch term (matches title fields)
langstringFilter by language (e.g., "english", "japanese")
artiststringFilter by artist name
tagsstringFilter by tag
categorystringFilter by category
parodystringFilter by parody/source
characterstringFilter by character
pageintegerPage number (default: 1)
limitintegerItems per page (default: 20, max: 100)
sortstringSort order: relevance, newest, oldest, pages_desc, pages_asc

Example Request

GET /api/v2/search?q=school&lang=english&page=1&limit=10&sort=newest

Example Response

{
  "success": true,
  "data": [
    { "id": 12345, "en_title": "...", "tags": [...], ... },
    { "id": 12346, "en_title": "...", "tags": [...], ... }
  ],
  "pagination": {
    "page": 1,
    "limit": 10,
    "total": 5234,
    "total_pages": 524,
    "has_next": true,
    "has_prev": false
  }
}

GET /api/v2/live-search

Search doujins directly from nhentai.net in real-time. Returns complete data with media_id and thumbnails.

Query Parameters

ParameterTypeDescription
qstringSearch term (required)
limitintegerMax results (default: 20, max: 50)

Example Request

GET /api/v2/live-search?q=school&limit=10
GET /api/v2/fetch/:id

Fetch a doujin from nhentai.net and save to database if complete (has media_id).

Example Request

GET /api/v2/fetch/12345
POST /api/v2/fetch/batch

Fetch multiple doujins and save complete ones to database (max 20 IDs).

POST /api/v2/fetch/batch
Content-Type: application/json

{ "ids": [39, 55, 59, 75, 76] }
⚠️ Note: Each fetch has a 10-second delay to avoid rate limits. Batch of 20 will take ~3.5 minutes.

🔄 Auto-Scraper (Real-time Data Enrichment)

API ini dilengkapi dengan auto-scraper yang secara otomatis melengkapi data yang tidak lengkap (JP_TITLE, ARTIST, TAGS, PAGES, UPLOAD_DATE, dll) dengan scrape real-time dari nhentai.net.

💡 Cara Kerja:
  • Saat Anda request GET /api/v2/:id, API akan mengecek apakah data di database lengkap
  • Jika ada field yang kosong (null/kosong), API akan otomatis scrape dari nhentai.net
  • Hasil scrape di-cache di memory (LRU cache, max 10.000 entries) untuk menghindari scrape berulang
  • Setiap request berikutnya untuk ID yang sama akan menggunakan cache
  • Scrape dilakukan via Cloudflare IP untuk memastikan koneksi stabil

Auto-Enrich (Default Aktif)

Semua endpoint GET /api/v2/:id dan GET /api/v2/random secara otomatis mengembalikan data lengkap.

# Data yang tadinya tidak lengkap akan otomatis terisi (real-time scrape)
curl "https://api-ao1hjzaox-akatsuki.vercel.app/api/v2/39"

// Response:
{
  "success": true,
  "data": {
    "ID": 39,
    "EN_TITLE": "[YUUKI ARISU] Akuma no Batsu...",
    "JP_TITLE": "...",           // ← Terisi otomatis!
    "ARTIST": "yuuki alice",    // ← Terisi otomatis!
    "TAGS": "group, lolicon",   // ← Terisi otomatis!
    "cover_url": "https://t.nhentai.net/galleries/814/cover.jpg",
    "thumbnail_url": "https://t.nhentai.net/galleries/814/thumb.jpg"
  },
  "meta": {
    "enriched": true,
    "scraped": true
  }
}

Manual Scrape by ID

Trigger manual scrape untuk ID tertentu.

GET /api/v2/scrape/:id
# Example
curl "https://api-ao1hjzaox-akatsuki.vercel.app/api/v2/scrape/12345"

// Response berisi: existing data, scraped data, dan merged data

Batch Scrape

Scrape multiple IDs sekaligus (max 50 IDs per request).

POST /api/v2/scrape/batch
Content-Type: application/json

{ "ids": [39, 55, 59, 75, 76] }

Cache Statistics

Melihat status cache scraper.

GET /api/v2/cache/stats
POST /api/v2/cache/clear
// Cache stats response:
{
  "success": true,
  "data": {
    "scrapeCache": 150,
    "notFoundCache": 23,
    "queueLength": 0,

Search with Enrich

Tambahkan parameter enrich=true di search untuk auto-enrich semua hasil.

# Search dengan auto-enrich
GET /api/v2/search?q=school&enrich=true&limit=10
⚠️ Perhatian: Menggunakan enrich=true pada search akan memperlambat response karena setiap hasil di-scrape. Gunakan hanya jika diperlukan.

Code Examples

JavaScript (Fetch)

// Search for doujins
const res = await fetch('/api/v2/search?q=school&limit=5');
const json = await res.json();
console.log(json.data);

// Get doujin by ID
const res = await fetch('/api/v2/12345');
const json = await res.json();
console.log(json.data.clean_title);

// Get random doujin
const res = await fetch('/api/v2/random');
const json = await res.json();
console.log(json.data);

Python (requests)

import requests

# Search for doujins
res = requests.get("https://api-ao1hjzaox-akatsuki.vercel.app/api/v2/search", params={
    "q": "school",
    "lang": "english",
    "limit": "10"
})
data = res.json()
print(data["data"])

# Get by ID
res = requests.get("https://api-ao1hjzaox-akatsuki.vercel.app/api/v2/12345")
print(res.json()["data"])
